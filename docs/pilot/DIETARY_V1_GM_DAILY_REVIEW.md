# Dietary V1 — GM Daily Review

Facility-wide Dietary pilot review. Two primary signals: **staffing coverage** and **meal-service timing**.

## Staffing coverage

Open **Today → Coverage** (with Assignments enabled).

Answer:

- How many required positions are Covered?
- Which Units are Uncovered or At Risk?
- How many scheduled Employees remain unassigned?
- How many call-offs affect coverage?
- Is the Assignment plan confirmed?
- When was it last changed, and who confirmed it?

Use **Open Assignment Board** for source detail.

## Unassigned Employees / Call-offs

Coverage chips and the Assignment Board show unassigned scheduled Employees and call-off counts. Call-off does not erase Assignment history.

## Plan confirmation

Plan status appears on Coverage and the Assignment Board (`DRAFT` / `CONFIRMED` / `REOPENED` / `CLOSED`).

## Servery Ready / Meal Service Started

Inspect Unit Workspaces and meal-service logs / Operations Center meal exceptions.

Answer:

- Which Units confirmed Ready?
- Which have not confirmed Ready (Not Confirmed — not proof the event never occurred)?
- Which started service?
- Which started late?
- Was Service Started recorded without Ready?
- Which records synchronized from offline devices?
- Which require conflict review?

## Late Units / Not Confirmed

Late and Not Confirmed are timing confirmation states. Do not attribute delay to another Department without evidence.

## Conflict review

Conflicts appear on Unit Workspace. Supervisors resolve them; originals and resolutions remain.

## Source-record inspection

Every Dashboard / Coverage status should trace to Facility, Department, Unit, operational date, Assignment or Milestone, and actor. Use Assignment Board history and Unit Milestone history — do not rely on a single generalized report platform for this pilot.

## Limitations

- Staffing coverage ≠ meal-service success.
- Formal plan CLOSED / end-of-day close UI is not required for this pilot.
- Milestone corrections should be entered on Facility-local devices (see time-zone note in certification).

## Constitutional decisions (locked)

1. Experiences are declarative operational applications.  
2. Hierarchy: Experience → Section → Card → Widget (+ hosted Tools).  
3. Projection emits contracts/descriptors only — never components.  
4. Layout is descriptor-based regions/templates.  
5. Component Registry maps keys → UI outside Projection.  
6. Homes adapt density; Experiences own section meaning/order.  
7. Runtime Overlay attaches live truth without mutating Projection.  
8. No bespoke Experience pages as the long-term pattern.

## Certification statement

LTC Manager assembles operational UI through one Experience Composition Framework. Developers declare sections, cards, widgets, actions, tools, and overlay slots; Projection decides presence; homes adapt density; engines fill overlays; the Component Registry renders. Bespoke module pages are not the constitutional path for new operational capability.

# Dietary Work — Supervisor Guide

The Operations Board surfaces Work exceptions (due, past due not confirmed, conflicts) alongside staffing, readiness, evidence, and assets.

## Actions

- Reassign occurrence-level Work (does not change the Operational Assignment).
- Mark Not Required with a reason.
- Reopen completed / not-required Work when needed.
- Create one-off Work for the Unit (optional employee target).

All mutations go through Department Work occurrence services — not Wave Task and not direct Assignment edits.

## Language

Use neutral **past due not confirmed** — do not say Work failed solely because it is unconfirmed.
